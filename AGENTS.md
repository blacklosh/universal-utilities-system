# AGENTS.md

## Проект

Universal Utility Tool — локальный каталог инструментов для работы и повседневных задач. Сервер использует Python 3.14, FastAPI и Uvicorn. Интерфейс написан на Jinja2, CSS и JavaScript. Работай из корня этого репозитория.

Перед изменениями проверь `git status --short --branch` и последние коммиты. Существующие пользовательские изменения сохраняй.

## Где искать код

- `app.py` подключает маршруты, шаблоны и статические файлы. Главная страница каталога находится в `templates/catalog.html`.
- `uuid_tool.py` содержит страницу и API генератора UUID v4/v7.
- Base64 и JWT работают в браузере. Их шаблоны находятся в `templates/`, скрипты — в `static/`. Содержимое файлов, JWT и секретные ключи должны обрабатываться локально в браузере.
- `README.md` содержит инструкции для пользователей. Обновляй его при изменении способов запуска или возможностей каталога.

## Запуск и проверка

- Для запуска после клонирования используй `docker compose up --build -d --wait`. По умолчанию адрес приложения — `http://127.0.0.1:8000/`. Если порт уже занят локальной копией, задай `APP_PORT` для Compose.
- Для фонового запуска напрямую на Windows используй `start.cmd`, для остановки — `stop.cmd`, для перезапуска — `restart.cmd`.
- При изменении инструмента проверь его страницу и основной сценарий. При изменении Docker-конфигурации проверь `docker compose config --quiet`, сборку и запуск.
- После каждого завершённого и проверенного шага сделай коммит и отправь его в `origin/main`. Затем проверь состояние ветки.

## Менеджер задач

Доска задач и схема SQLite находятся в `tasks_tool.py`. Версия схемы хранится в `PRAGMA user_version`. Путь к базе — `data/tasks.sqlite3` относительно корня приложения. В Docker каталог `/app/data` уже подключён к постоянному тому `app-data`. Храни в Git код и миграции, а локальные базы, журналы и секреты оставляй вне репозитория.

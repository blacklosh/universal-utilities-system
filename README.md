# Universal Utility Tool

Локальный каталог инструментов для работы и повседневных задач. Приложение написано на Python и FastAPI. Интерфейс открывается в браузере, сервер принимает подключения только с этого компьютера.

## Инструменты

- **Генератор UUID** создаёт от 1 до 1000 идентификаторов за запуск. UUID v4 использует случайные данные, UUID v7 включает текущую метку времени Unix в миллисекундах. Результат можно скопировать целиком, по одному UUID на строку.

- **Конвертер Base64** кодирует текст UTF-8 и файлы в Base64. Отдельный блок декодирует Base64 в текст UTF-8. Обе операции выполняются в браузере, результаты можно скопировать.

## Установка на Windows

Понадобятся Git и Python 3.14 или новее. Версия Python важна, поскольку генератор использует встроенную функцию `uuid.uuid7()`.

Для новой копии выполните в PowerShell:

```powershell
git clone https://github.com/blacklosh/universal-utilities-system.git
Set-Location universal-utilities-system
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если у вас уже есть локальная копия, выполните две последние команды из папки проекта. Если Python установлен без команды `py`, используйте `python -m venv .venv` после проверки версии командой `python --version`.

## Запуск

- Откройте `start.cmd`, затем перейдите в [каталог](http://127.0.0.1:8000/).
- Сервер работает в фоне после закрытия окна запуска. Журнал сервера доступен в `server.log`.
- Для остановки используйте `stop.cmd`.
- Для перезапуска используйте `restart.cmd`. Если сервер выключен, скрипт запустит его.

## Структура проекта

- `app.py` — приложение FastAPI и главная страница каталога.
- `uuid_tool.py` — страница и API генератора UUID.
- `templates/` и `static/` — шаблоны Jinja2, стили и JavaScript.
